RAICES SSL/TLS SECTIGO PARA TICKETBAI  (Araba / Bizkaia / Gipuzkoa)
===================================================================

QUE ES ESTO
-----------
Las Haciendas Forales cambian el certificado SSL/TLS de sus servidores
TicketBAI a la nueva jerarquia de Sectigo.
  - Preproduccion: 01-10-2026
  - Produccion:    entre noviembre 2026 y enero 2027

Este cambio afecta solo al certificado que presenta el SERVIDOR de Hacienda
al conectar. No cambia la forma de las facturas ni sus firmas.

CUANDO HACE FALTA
-----------------
SOLO si un equipo da ERROR SSL/TLS al enviar a Hacienda (equipos antiguos
cuyo Windows no confia en la cadena nueva). En equipos actualizados NO hace
falta: Windows ya confia en la cadena y funciona solo.

QUE HACE
--------
Instala en "Entidades de certificacion raiz de confianza" del EQUIPO las
dos raices Sectigo:
  - Sectigo Public Server Authentication Root R46  (la necesaria ahora)
  - Sectigo Public Server Authentication Root E46  (preventiva, futuro ECC)

COMO USARLO
-----------
1) Descargar el ZIP  raices-sectigo-ticketbai.zip  en el equipo del cliente.
2) Descomprimirlo en una carpeta.
3) Clic derecho en  instalar-raices-sectigo.bat  >  "Ejecutar como administrador".

Es idempotente: si las raices ya estan, no hace nada.

COMPROBAR QUE ESTA
------------------
  certutil -store Root "Sectigo Public Server Authentication Root R46"
  certutil -store Root "Sectigo Public Server Authentication Root E46"

HUELLAS (SHA1) para verificar los .cer
--------------------------------------
  R46:  AD98F9F3E47D753B65D482B3A45217BB6EF5E438
  E46:  EC8A396C40F02EBC4275D49FAB1C1A5B67BED29A

NOTA
----
NO instalar el certificado final del servidor: se renueva periodicamente.
Solo las raices (R46/E46), que son estables.
